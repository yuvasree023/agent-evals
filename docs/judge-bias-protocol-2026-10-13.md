# Frozen-judge bias experiment protocol

Predeclared 2026-10-13, before new verdict calls. 12 selected Groq-generated v2 dev trace-sheet rows: V01, V04, V07, V10, V13, V14, V15, V16, V19, V21, V25, V27. Selection spans confirmation, target ambiguity, missing IDs, read status, ownership refusal, eligibility and shipping wording. No selection based on new verdicts, no holdout.

Each case receives four fresh uncached calls: unchanged base, unchanged base repeat, reversed few-shot example order, and answer repeated verbatim three times. 48 calls total, sequentially paced by providers.py on free Gemini 3.5 Flash Lite. Fixed-seed shuffled variant order within each case reduces a fixed execution-order confound. Stop at any provider error/quota exhaustion, preserve completed rows and report complete matched cases only; no paid/provider fallback or billing card.

Frozen judge/judge.py, judge/validate.py, policy.md and original human label file stay byte-identical. Few-shot contents and labels are the historical train-case set and order saved in results/judge-validation-dev-2026-10-12.json; only reversed_examples changes order. The full prompt, payload and source file hashes are recorded. Human labels for these v2 rows remain unknown; no accuracy is computed.

Compare each changed variant with base and report the base-repeat flip rate alongside it. A changed verdict can reflect stochastic variation; this small one-repeat control cannot cleanly isolate causality. Repeated answer wording can change perceived quality and is a verbosity stress test, not proof of semantic equivalence. Reversing demonstration order measures demonstration-order sensitivity, not position preference between two candidate answers.

These source v2 traces were generated by Groq, while the judge is Gemini. This avoids same-model-family agent/judge generation in this particular experiment, but does not establish independent judge correctness. The frozen rubric was originally written after seeing the old v1 labels, so its historical accuracy contamination remains. Gemini-only v1-v4 exploratory generation results are a separate experiment and must not be described as independently validated by this bias test.
